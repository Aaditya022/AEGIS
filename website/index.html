Why AEGIS?

The Problem

AI agents operate with unfettered access to tools, databases, and credentials. System prompts are advisory, not enforced. Application guardrails share the agent's address space.

The Solution

External, transparent governance that intercepts all agent-resource communication. Non-bypassable policy enforcement via Two-Plane Verification.

Framework Agnostic

Works with LangGraph, CrewAI, AutoGen, OpenAI SDK, MCP, Google ADK, and any future framework. No code changes required.

Quick Start

# Prerequisites: Rust, Go, Docker
git clone https://github.com/aegis-ai/aegis
cd aegis

# Start dev environment
make dev-env

# Build and test
make build
make test

# Deploy to Kubernetes
helm install aegis deploy/kubernetes/charts/aegis
